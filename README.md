# Week 13 - Complex Analysis Project

## Project Overview
This project combines sales data from August and September to understand how the business performed, which regions performed best, and what type of customers we have.

## Data
- Files used: sales_august.csv and sales_september.csv
- Combined: 441 rows
- Total revenue: KES 69,997,000

## Findings

Over August and September, the business made a total of KES 69,997,000 from 441 sales. September brought in far more money than August, which shows sales grew strongly in September. The main regions were Kampala, Mpigi, Mukono, and Wakiso. Most customers were in the Low tier, which means the business depends on many small customers rather than a few big ones.

## Charts
All charts are saved in the `charts` folder:
- Revenue by Region
- Revenue: August vs September
- Customer Revenue Tiers

## How to Run
1. Open the folder in VS Code
2. Run `python distributors_order_analysis.py`
3. Check the `charts` folder for the graphs
